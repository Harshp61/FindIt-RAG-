⚠️ Project Status: Paused

This project is currently paused due to hardware limitations.

During extended processing, especially while running models for long durations, the system encounters memory crashes. These crashes interrupt and terminate the audio chunking pipeline, preventing successful completion of tasks.

Despite using an NVIDIA RTX 3050 and a 12th Gen Intel i5 processor, the available system memory and GPU resources are insufficient to handle sustained model execution for this workload.

📌 Reason for Pause

Memory overflow during long model runs

Audio chunking process crashes mid-execution

Hardware constraints limit stable processing

🔄 Future Plans

The project will resume once:

Hardware resources are upgraded, or

The pipeline is optimized to reduce memory consumption

Thank you for your understanding.
